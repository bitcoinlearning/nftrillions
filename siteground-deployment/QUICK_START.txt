🚀 DEPLOYMENT IN 5 STEPS:

   1. UPLOAD FILES
      → Use FTP/SFTP to upload ALL files to your SiteGround hosting
      → Upload to: public_html (or your domain folder)

   2. INSTALL DEPENDENCIES (via SSH)
      → SSH into your server
      → Navigate to your website folder: cd ~/public_html
      → Run: npm install --production

   3. CONFIGURE NODE.JS APP
      → SiteGround Site Tools > Devs > Node.js
      → Create new app
      → Set startup file: dist/index.js
      → Node.js version: 18.x or higher

   4. START YOUR APP
      → In Site Tools > Node.js
      → Click "Start" on your application

   5. VERIFY
      → Visit your domain
      → Check homepage, NFT pages, legal pages all load
