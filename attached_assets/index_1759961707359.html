How It Works

Simple rules, transparent supply, on-chain forever.

Solana Only (for now)

We’re launching on Solana with a hard cap of 1,000 NFTs. Each represents a $100B debt milestone.

Unlock Logic

As official U.S. debt increases, the next slice is released from the treasury wallet. New drops are announced with on-chain proofs.

Royalties

Creator fees are set to 5–10% in metadata and honored where marketplaces enforce royalties.

Per-Slice Education

Each slice will have its own page (e.g., /slices/370) with CPI, rates, curated headlines, and a short historical note for that period.

BTC & BNB (Later)

Bitcoin will host 100 “Trillion Slices” (1 per $1T). BNB will mirror Solana’s $100B slices. Both live on dedicated pages separate from this Solana collection.

No. NFTrillions is a satirical digital art/collectible project. There’s no promise of profit or yield.

How are new slices released?

One new Solana NFT per +$100B in U.S. debt. We publish on-chain proofs and update a public manifest.

Where can I trade?

Any Solana marketplace (e.g., Magic Eden, Tensor). Royalties are set in metadata and honored where enforced.

What about Bitcoin & BNB?
